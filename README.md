# Чатор — Android

**Чатор** is a fork of [Element X Android](https://github.com/element-hq/element-x-android) — a private [Matrix](https://matrix.org/) messenger with a Russian-language interface and custom branding.

It uses the [Matrix Rust SDK](https://github.com/matrix-org/matrix-rust-sdk) underneath and targets Android 7+. The UI layer is written using [Jetpack Compose](https://developer.android.com/jetpack/compose), and the navigation is managed using [Appyx](https://github.com/bumble-tech/appyx).

**Homeserver:** `chator.duckdns.org`

## Rust SDK

This project uses the [Matrix Rust SDK](https://github.com/matrix-org/matrix-rust-sdk) through an FFI layer. It is a fork of [Element X Android](https://github.com/element-hq/element-x-android).

## Minimum SDK version

Requires a minimum SDK version of 24 (Android 7.0, Nougat).

## Build instructions

Clone the repo and open it in Android Studio. Select the `app` configuration when building. Build via CI:

```bash
./gradlew :app:assembleGplayDebug
```
