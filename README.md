## О проекте

Чатор — это форк [Element X Android](https://github.com/element-hq/element-x-android) с собственной брендинговой идентичностью и русскоязычным интерфейсом.

Под капотом — [Matrix Rust SDK](https://github.com/matrix-org/matrix-rust-sdk), UI написан на [Jetpack Compose](https://developer.android.com/jetpack/compose).

## ✨ Особенности

| | |
|---|---|
| 🇷🇺 | Полностью русский интерфейс |
| 🎨 | Собственный брендинг и логотип |
| 📞 | Групповые звонки через Jitsi Meet |
| 🏢 | Enterprise-модуль включён |
| 🔒 | На базе Matrix — децентрализованный и шифрованный |

## 📋 Требования

- **Android 7.0** (API 24) и выше — для обычной версии
- **Android 13** (API 33) и выше — для Enterprise-версии

## 🛠 Сборка

```bash
git clone https://github.com/mamalubitlal/element-x-android.git
cd element-x-android
```

Откройте проект в Android Studio и выберите конфигурацию `app`.

Подробнее: [docs/_developer_onboarding.md](docs/_developer_onboarding.md)
