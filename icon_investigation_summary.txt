KEY FINDINGS:
-------------
1. The app uses dynamic icon modules based on build type:
   - Enterprise builds: use appicon.enterprise module
   - Non-enterprise (chator) builds: use appicon.chator module + enterprise foss features

2. The chator icon module defines adaptive icons with:
   - Background: @drawable/ic_launcher_background_chator
   - Foreground: @mipmap/ic_launcher_foreground_chator
   - Monochrome: @mipmap/ic_launcher_monochrome_chator (for Android 8.0+)

3. The AndroidManifest.xml references:
   - android:icon="@mipmap/ic_launcher" 
   - android:roundIcon="@mipmap/ic_launcher_round"

4. Both chator and element icon modules have v26 adaptive icons with monochrome support,
   while the enterprise module uses legacy adaptive icons (no v26 qualifier) without monochrome.

5. The chator and element icon modules are structurally identical except for resource names
   (chator_* vs element_* vs no suffix for default element).
