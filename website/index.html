Возможности

🇷

Полностью русский интерфейс

Весь интерфейс переведён на русский язык — без английских вставок и недопереведённых меню.

🎨

Собственный брендинг

Уникальный логотип, цветовая палитра и название — Чатор это не просто клон.

📞

Групповые звонки

Голосовые и видеозвонки через Jitsi Meet — без ограничений на количество участников.

🏢

Enterprise-модуль

Дополнительные возможности для корпоративного использования — SSO, OIDC и не только.

🔒

Шифрование

Сквозное шифрование по умолчанию на базе Matrix протокола — никто не прочитает.

🌐

Децентрализация

Работает на любом Matrix-сервере. Нет единой точки отказа — и никто не может заблокировать.

О технологии

Matrix

Открытый стандарт для децентрализованной коммуникации. Серверы общаются между собой — вы не привязаны к одному провайдеру. Протокол используется в правительственных организациях, армии и больницах по всему миру.

Узнать больше о Matrix

Технологический стек

  • matrix-rust-sdk — ядро обработки протокола Matrix на Rust
  • Jetpack Compose — современный UI на Kotlin
  • Jitsi Meet — открытая видеоконференция
  • OIDC / SSO — корпоративная аутентификация
